# Preventivo MVP v2 — UI/UX Android feel

Cambios implementados sobre el MVP:
- Barra superior simple tipo app.
- Formulario sin tarjeta/sombra.
- Selección de pieza mediante bottom sheet.
- Botón principal fijo en la zona inferior.
- Cámara a pantalla completa con cierre superior.
- Shutter de mayor tamaño y feedback táctil.
- Vista previa con una sola acción de repetir y una de guardar.
- Estados visuales de información, error y éxito.
- Confirmación visible al guardar.
- Área táctil mínima amplia para controles.
- Íconos SVG en lugar de emoji.
- Animaciones sutiles.
- Mantiene HTML/CSS/JavaScript y la lógica funcional del MVP.
